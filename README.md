# 🛡️ Discord Moderation Bot (Python)

moderation bot for Discord servers—built in Python with essential tools for server management.

---

## 🚀 Features

- 🔨 **Ban & Kick Commands**
  - `/ban` and `/kick` with reason and user mention
  - Silent variants: `/silentban`, `/silentkick` for stealth moderation

- 📢 **Announcements**
  - Sends public embed messages for bans and kicks
  - Customizable formatting and target channels

- 🧾 **Logging**
  - Logs all actions with timestamp, moderator, and reason

- ⚙️ **Simple Setup**
  - No complex config. just user your bot token and host it---

## 🧑‍💻 Getting Started

1. **Clone the repository**
```
   git clone https://github.com/Ashwath-Palanisamy/Moderation-bot.git
   cd Moderation-bot
```

Install dependencies

pip install -r requirements.txt

# Add your bot token
Open main.py
create bot.txt in the same folder
paste your bot token in bot.txt file
